# @ronradtke/react-native-device-calendar

Read and write the iOS and Android device calendars from React Native: a small Turbo Module on EventKit and CalendarContract

## Installation


```sh
npm install @ronradtke/react-native-device-calendar
```


## Usage


```js
import { multiply } from '@ronradtke/react-native-device-calendar';

// ...

const result = multiply(3, 7);
```
