# Security policy

## Supported versions

Security fixes go into the latest release. Please update to it before reporting.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/RonRadtke/react-native-device-calendar/security/advisories/new)
with the version, the platform and the steps that show the problem.

You get an answer within a week. Once a fix is released, the advisory is published with credit to you unless you prefer
otherwise.

The library reads and writes calendar data only on the device it runs on and sends nothing over the network.
